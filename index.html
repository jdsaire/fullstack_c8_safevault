⚙️ Activity 1 Defensive Architecture Summary

WCAG 2.1 AAA Compliant

1. Input Validation

Enforces strict character sets (^[a-zA-Z0-9_.-]+$), length limits (3–50 chars), and RFC 5322 email constraints before data enters the system.

2. Dual-Stage Sanitization

Strips client-side dangerous tags and applies server-side WebUtility.HtmlEncode so special characters cannot execute as code in the DOM.

3. Parameterized Queries

Zero string concatenation in SQL commands. Inputs are bound strictly as data values via SqliteParameter, preventing SQL injection.

4. Automated Tests

8 NUnit security tests verify input boundaries, tautology injections, and script vectors under isolated in-memory test fixtures.
