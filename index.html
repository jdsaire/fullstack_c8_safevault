⚙️ Cumulative Defensive Architecture (Activities 1, 2 & 3)

WCAG 2.1 AAA Compliant

1. Hardened Input & Email Regex

Enforces strict character sets, 250ms regex timeouts, ASCII control-char rejection, and hardened email validation blocking angle brackets and quotes (V1 [M]).

2. Obfuscated XSS Sanitization

Strips control bytes, all on[a-z0-9_]+= event attributes, and whitespace-obfuscated javascript:/vbscript:/data:text/html URIs before WebUtility.HtmlEncode.

3. Parameterized Queries & Search

Zero SQL string concatenation. Enforces UNIQUE usernames, static DDL allowlists, and wildcard-safe LIKE @SearchPattern ESCAPE '\' search (V2 [M]).

4. Salted BCrypt (Cost 4–31)

Hashes passwords via BCrypt.Net-Next (cost 12 default, standard bounds 4–31 enforced in V4 [M]) with constant-time anti-enumeration login checks.

5. RBAC, Token Guards & Headers

Rejects pipe (|) delimiter injection in HMAC session claims and emits defensive HTTP headers (Content-Security-Policy, X-Frame-Options: DENY, V3 [M]).

6. 28 NUnit Security Tests

8 Activity 1 tests + 10 Activity 2 tests + 10 Activity 3 remediation & regression tests verified against in-memory SQLite (100% pass rate).
